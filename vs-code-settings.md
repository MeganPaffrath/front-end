# VS Code Settings

- Extentions to install
  - `Prettier`: formats code
  - `One Monokai Theme`: sets color theme (install then set as theme)
- Settings to set
  - `Default Formatter`: Set to `Prettier - Code Formatter`
  - `Format on save`: Check the box
  - `Auto Save`: set to `onFocusChange` (automatically saves when you change tabs / leave window)
  - `Tab size`: set to `2`
